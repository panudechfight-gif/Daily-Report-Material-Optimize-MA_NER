Action 1 — Recurrence (จับเวลา)

ตั้งให้ Flow ยิงทุกวันจันทร์ 08:00 น. ตามเวลาไทย

 ▼
ℹ️
Flow สร้าง action นี้ให้อัตโนมัติตอนเลือก Scheduled cloud flow แล้ว เราแค่เข้าไปปรับค่าให้ถูก

ขั้นตอน

  1. กดที่ action Recurrence
  2. กด Show advanced options เพื่อเปิดช่องที่ซ่อนอยู่
  3. ตั้งค่าตามตารางข้างล่าง

ข้อแนะนำที่ใช้ได้จริง

  1. แยกเป็น 2 Flow อย่ายัดรวมใบเดียว — คนละกลุ่มผู้อ่าน คนละความถี่ ถ้ารวมกัน คนหน้างานต้องเลื่อนผ่านข้อมูลรายเดือนทุกสัปดาห์
  2. แยกห้อง Teams หรืออย่างน้อยแยก thread — MA อยู่ห้องปฏิบัติการ OPTIMIZE อยู่ห้องวางแผน คนจะได้ไม่ต้องกรองเอง
  3. MA ควรสั้น สัปดาห์ไหนไม่มีรายการเสี่ยงเลย การ์ดที่บอกว่า "ปกติทั้งหมด" หนึ่งบรรทัดมีค่ากว่าตารางยาว ๆ — ทำได้ด้วย Condition เช็ก riskCount จาก Run script ก่อนโพสต์
  4. OPTIMIZE ควรมีการเทียบ ให้ผู้อ่านดู Prev_Before / Prev_Received คู่กับ OMC-Onhand เสมอ ถ้าอยากได้กราฟแนวโน้มจริง ๆ ให้ลิงก์ไป Dashboard แทนการยัดลงการ์ด
  5. ให้ทั้งสองใบชี้ไป Dashboard เดียวกัน การ์ดคือ "สัญญาณเตือน" ไม่ใช่รายงานฉบับเต็ม อะไรที่ต้องกรอง/ไล่ดูรายจังหวัด ให้จบที่ Dashboard
