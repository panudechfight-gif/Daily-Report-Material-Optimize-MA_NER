Action 1 — Recurrence (จับเวลา)

ตั้งให้ Flow ยิงทุกวันจันทร์ 08:00 น. ตามเวลาไทย

 ▼
ℹ️
Flow สร้าง action นี้ให้อัตโนมัติตอนเลือก Scheduled cloud flow แล้ว เราแค่เข้าไปปรับค่าให้ถูก

ขั้นตอน

  1. กดที่ action Recurrence
  2. กด Show advanced options เพื่อเปิดช่องที่ซ่อนอยู่
  3. ตั้งค่าตามตารางข้างล่าง

✓

Action 2 — Compose (เวลาที่สร้างรายงาน)

สร้างข้อความวันเวลาแบบไทย เช่น "17 Aug 2569 08:00 น."

 ▼
ℹ️
ข้อความนี้ไปแสดงที่ท้ายการ์ดว่า "🕗 สร้างรายงานเมื่อ 17 Aug 2569 08:00 น."

ขั้นตอน

  1. กด + New step
  2. ค้นหา Compose แล้วเลือก Compose (Data Operation)
  3. คลิกจุดสามจุดที่หัว action → Rename → ตั้งชื่อว่า GeneratedAt
  4. ในช่อง Inputs กดไอคอน fx แล้ววางสูตรข้างล่าง
วางลงในช่อง Inputs
concat(
  formatDateTime(convertFromUtc(utcNow(),'SE Asia Standard Time'),'d MMM '),
  string(add(int(formatDateTime(convertFromUtc(utcNow(),'SE Asia Standard Time'),'yyyy')),543)),
  ' ',
  formatDateTime(convertFromUtc(utcNow(),'SE Asia Standard Time'),'HH:mm'),
  ' น.'
)
💡
อยากได้ปี ค.ศ. แบบสั้น ๆ?
ใช้บรรทัดเดียวพอ: formatDateTime(convertFromUtc(utcNow(),'SE Asia Standard Time'),'dd/MM/yyyy HH:mm')
✓
ชื่อ action ต้องเป็น GeneratedAt เป๊ะ ๆ เพราะ Action 3 จะมาดึงค่าจากตรงนี้

สูตรขึ้นสีแดง?
แปลว่าชื่อ action ของคุณไม่ใช่ Run script — ให้ดูชื่อจริงที่หัว action แล้วเปลี่ยนช่องว่างเป็นขีดล่างในสูตร เช่น Run script 2 → body('Run_script_2')
ทางลัด: กดแท็บ Dynamic content แล้วเลือก result Power Automate จะเติมสูตรให้ จากนั้นค่อยครอบด้วย string(...)
⚠️
อย่าเอา 01_card-main.json ไปวางในช่องนี้
ไฟล์นั้นเป็น template ที่ยังมี ${...} อยู่ ซึ่ง Power Automate ไม่รู้จัก การ์ดจะขึ้นเป็นข้อความ ${meta.period} ตรง ๆ — คนที่แทนค่าให้คือ Office Script ใน Action 3 แล้ว
