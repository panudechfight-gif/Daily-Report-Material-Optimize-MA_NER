> 📄 อยากได้เช็กลิสต์แบบติ๊กบนจอ (จำสถานะให้ด้วย) เปิด
> [`flow-guide-artifact.html`](flow-guide-artifact.html) — เป็นคู่มือทีละ Action พร้อมเช็กลิสต์ในตัว

## ระยะ C — ติดตั้ง Office Script

| ☐ | รายการ | วิธีตรวจว่าผ่าน |
|---|---|---|
| ☐ | C1. เปิดไฟล์ `.xlsx` ใน Excel for the web | URL ขึ้นต้นด้วย `.sharepoint.com` |
| ☐ | C2. Automate → New Script | Code Editor เปิดทางขวา |
| ☐ | C3. ลบโค้ดตัวอย่างออกหมด | Editor ว่างเปล่า |
| ☐ | C4. วางเนื้อ `office-scripts/renderAdaptiveCard.ts` ครบทั้งไฟล์ | บรรทัดสุดท้ายต้องเป็น `}` ปิด `main` |
| ☐ | C5. ตั้งชื่อสคริปต์ `renderAdaptiveCard` | ชื่อที่หัว Editor ตรงกัน |
| ☐ | C6. กด Save script | ไม่มีข้อความ error ค้าง |
| ☐ | C6b. ไม่มีขีดหยักแดงเรื่องไวยากรณ์ | ดูรายการ error ที่พบบ่อยในกล่องข้างล่าง |
| ☐ | C7. กด **Run** แล้วได้ JSON | Output ขึ้นต้น `{"type":"AdaptiveCard"` |
| ☐ | C8. JSON ที่ได้ไม่มี `${` เหลืออยู่ | ค้นหา `${` ใน Output ต้องไม่เจอ |

> ❗ **C7 error "ไม่พบชีต"** → กลับไป B4
> ❗ **C7 error "ไม่พบคอลัมน์: ..."** → กลับไป B5 / B6

> ❗ **C6b ขึ้น error ไวยากรณ์** — Office Scripts เข้มกว่า TypeScript ทั่วไป
> ทั้งสองข้อนี้แก้ไว้แล้วในสคริปต์ตัวล่าสุด ถ้ายังเจอแปลว่าใช้ไฟล์เก่า
> ให้คัดลอก `office-scripts/renderAdaptiveCard.ts` ไปวางทับใหม่
>
> | ข้อความ error | สาเหตุ |
> |---|---|
> | `Only arrow functions may be used in array method callbacks` | ส่งชื่อฟังก์ชันเข้า `.sort()` ตรง ๆ ต้องเป็น `.sort((a, b) => ...)` |
> | `'Object' is not supported` | ประกาศชนิดที่คืนค่าเป็น `object` ต้องเป็น `(string \| number \| boolean \| object)` |
